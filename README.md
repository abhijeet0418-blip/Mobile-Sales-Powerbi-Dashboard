# 📊 Mobile Sales Analytics Dashboard | Power BI
An interactive Mobile Sales Analytics Dashboard developed using Microsoft Power BI to analyze sales performance, transactions, customer ratings, payment methods, mobile models, cities, months, and days.

## 📌 Project Overview
This project provides an interactive view of mobile sales data and helps understand key business performance indicators.

The dashboard allows users to explore sales performance using multiple filters and visualizations.

## 📈 Key KPIs
- Total Sales: 769M
- Average Sales: 40K
- Total Transactions: 4K
- Total Quantity: 19K

## 📊 Dashboard Features
The dashboard includes:

- Total Sales by Month
- Total Sales by City
- Total Sales by Mobile Model
- Transaction Analysis by Payment Method
- Customer Ratings Analysis
- Total Sales by Day Name
- Year-wise filtering
- City filtering
- Month filtering
- Payment Method filtering
- Customer Name filtering
- Mobile Model filtering

## 🔍 Key Insights
The dashboard helps identify:

- Monthly sales trends
- Top-performing mobile models
- City-wise sales performance
- Preferred payment methods
- Customer rating distribution
- Day-wise sales performance
- Overall sales and transaction performance
